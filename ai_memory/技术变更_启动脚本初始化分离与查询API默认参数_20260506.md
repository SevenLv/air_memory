# 技术变更_启动脚本初始化分离与查询API默认参数_20260506

## 标签

启动脚本, 初始化脚本, init.sh, init.bat, start.sh, start.bat, fast_only, 查询API, 热层, 可移植性, v1.3.0

## 变更内容

### 1. 初始化脚本与启动脚本分离

新增 `init.sh`（macOS/Linux）和 `init.bat`（Windows），负责一次性环境初始化：

- 检查 Python 3.11+
- 以 `--copies` 模式创建 `.venv`（支持目录跨机器迁移）
- `pip install -r backend/requirements.txt` 安装依赖
- 预下载 Embedding 模型（`all-MiniLM-L6-v2`），`HF_HOME` 指向 `./models/`

`start.sh` / `start.bat` 简化为：检查 `.venv` 是否存在 → 激活虚拟环境 → 设置环境变量 → `python -m uvicorn` 启动。

### 2. 查询 API 默认参数变更

- `GET /memories`：`fast_only` 默认值 `False` → `True`
- MCP `query_memory`：`fast_only` 默认值 `False` → `True`
- 影响：不传参时默认只搜索热层；深度搜索需显式传入 `fast_only=false`

### 3. 可移植性方案

`venv --copies` + `HF_HOME` 指向项目目录，确保整个目录可复制到相同 OS/架构机器后直接运行。
